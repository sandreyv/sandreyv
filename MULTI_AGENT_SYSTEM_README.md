# Многоагентная система анализа и редактирования текстов

Профессиональная система для комплексного анализа, проверки и редактирования текстов с использованием 12 специализированных AI-агентов на базе Claude.

## Описание

Система обеспечивает глубокую обработку текстов через последовательную работу специализированных агентов, каждый из которых выполняет свою уникальную функцию.

## Архитектура системы

### 12 Агентов системы

1. **Мета-агент (начало)** — Анализирует задачу, определяет контекст и подготавливает документ
2. **Анализатор фактуры Первый** — Проверяет текст на экспертность, оставляет комментарии
3. **Анализатор фактуры Второй** — Перепроверяет и добавляет свои комментарии
4. **Анализатор фактуры Третий** — Финальный анализ фактуры
5. **Шеф-редактор** — Проверяет смыслы, логику, принимает решения по комментариям
6. **Рессёрчер-фактчекер** — Детально проверяет каждый факт через интернет
7. **Рессёрчер-general** — Перепроверяет факты независимо
8. **Рессёрчер-post-general** — Находит замену неподтверждённым фактам, вносит правки
9. **Агент по стилистике** — Удаляет комментарии, вычитывает по стилю
10. **Главред** — Финальная проверка фактов, смыслов, повторов, логики
11. **Корректор** — Исправляет орфографию, пунктуацию, грамматику
12. **Мета-агент (конец)** — Генерирует финальный отчёт

## Установка

### Требования

- Python 3.8+
- API ключ Anthropic

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd sandreyv
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте API ключ:
```bash
# Создайте файл .env на основе примера
cp .env.example .env

# Отредактируйте .env и добавьте ваш API ключ
# ANTHROPIC_API_KEY=your_api_key_here
```

Или установите переменную окружения:
```bash
export ANTHROPIC_API_KEY='your_api_key_here'
```

## Использование

### Базовое использование

```bash
# Запуск с файлом
cd multi_agent_review_system
python main.py /path/to/your/text.txt

# Запуск с примером текста
python main.py --example
```

### Программное использование

```python
from multi_agent_review_system import MultiAgentReviewSystem

# Инициализация системы
system = MultiAgentReviewSystem(api_key='your_api_key')

# Обработка текста
text = """
Ваш текст для обработки...
"""

result = system.process_text(text, save_results=True)

# Получение финального текста
final_text = result['document'].current_text
print(final_text)

# Получение отчёта
report = result['report']
print(report)
```

## Особенности работы агентов

### Анализаторы фактуры (1-3)
- Последовательно анализируют текст
- НЕ правят текст, только оставляют комментарии
- Каждый следующий видит комментарии предыдущих

### Шеф-редактор
- Принимает стратегические решения
- Может удалять лишние комментарии
- Фокусируется на смыслах и логике

### Рессёрчеры (фактчекер, general, post-general)
- Проверяют КАЖДЫЙ факт через интернет
- Ищут только авторитетные первоисточники
- Post-general — единственный, кто ВНОСИТ правки в текст

### Агент по стилистике
- УДАЛЯЕТ все комментарии
- Вычитывает по стилистическим правилам
- Подготавливает текст для финальной проверки

### Главред
- Комплексная финальная проверка
- Проверяет факты, смыслы, повторы, логику
- Может менять структуру повествования

### Корректор
- Последний этап перед финалом
- Исправляет все ошибки
- Текст должен быть идеальным

### Пример 2: Пакетная обработка


## Настройка и расширение

### Добавление своего агента

1. Создайте класс, наследующий `BaseAgent`
2. Реализуйте методы `get_system_prompt()` и `process()`
3. Зарегистрируйте агента в координаторе

```python
from multi_agent_review_system.core.base_agent import BaseAgent, TextDocument

class MyCustomAgent(BaseAgent):
    def __init__(self, api_key=None):
        super().__init__(name="Мой агент", api_key=api_key)

    def get_system_prompt(self) -> str:
        return "Промпт для вашего агента..."

    def process(self, document: TextDocument) -> TextDocument:
        # Ваша логика обработки
        return document
```

### Изменение порядка агентов

Отредактируйте метод `_register_agents()` в `main.py`:

```python
def _register_agents(self):
    agents = [
        # Ваш порядок агентов
    ]
    for agent in agents:
        self.coordinator.register_agent(agent)
```

## Важные замечания

1. **Использование API**: Система делает много запросов к Claude API. Учитывайте лимиты и стоимость.

2. **Фактчекинг**: Агенты-рессёрчеры используют Claude для поиска информации. Реальный поиск в интернете требует интеграции с поисковыми API (Google, Bing, и т.д.).

3. **Время обработки**: Полная обработка текста через всех агентов может занять значительное время (зависит от длины текста).

4. **Качество результатов**: Качество зависит от:
   - Качества исходного текста
   - Правильности промптов агентов
   - Модели Claude (используется claude-sonnet-4-5-20250929)

## Troubleshooting

### Ошибка: API ключ не найден
```
ValueError: API ключ Anthropic не найден
```
**Решение**: Установите переменную окружения `ANTHROPIC_API_KEY` или передайте ключ явно.

### Ошибка: Превышен лимит токенов
```
anthropic.RateLimitError
```
**Решение**: Подождите или увеличьте лимиты в настройках Anthropic API.

### Ошибка: Модуль не найден
```
ModuleNotFoundError: No module named 'anthropic'
```
**Решение**: Установите зависимости: `pip install -r requirements.txt`
