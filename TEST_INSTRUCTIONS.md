# Инструкция по тестированию текста через многоагентную систему

## Быстрый старт

### 1. Установите зависимости (если ещё не установлены)

```bash
pip install -r requirements.txt
```

### 2. Настройте API ключ Anthropic

Получите ключ на: https://console.anthropic.com/

Затем установите его:

```bash
export ANTHROPIC_API_KEY='your_api_key_here'
```

Или создайте файл `.env`:

```bash
cp .env.example .env
# Отредактируйте .env и добавьте ваш API ключ
```

### 3. Запустите тестирование

```bash
python run_test.py
```

## Что произойдёт

Система обработает тестовый текст через всех 12 агентов:

1. **Мета-агент** — проанализирует контекст
2. **3 Анализатора фактуры** — проверят экспертность
3. **Шеф-редактор** — оценит смыслы и логику
4. **3 Рессёрчера** — проверят факты
5. **Агент по стилистике** — вычитает стиль
6. **Главред** — финальная проверка
7. **Корректор** — исправит ошибки
8. **Мета-агент** — создаст отчёт

Ожидаемое время обработки: 5-15 минут (зависит от нагрузки API)

## Результаты

После обработки вы получите:

- **Финальный текст** — в консоли и в файле
- **Подробный отчёт** — в директории `output/`
- **Лог выполнения** — в директории `output/`

## Что обнаружат агенты в тестовом тексте

### Ожидаемые комментарии:

1. **Фактура:**
   - Нечёткое начало ("Данные источники")
   - Отсутствие пояснений к техническим терминам
   - Нужно обоснование утверждений о лидерстве

2. **Смыслы:**
   - Отсутствует введение
   - Неясна цель текста
   - Нет выводов

3. **Фактчекинг:**
   - "90+ сервисов" — нужен источник
   - YTsaurus, YDB — нужны ссылки
   - GigaChat — нужна ссылка
   - IT Bootcamp, One Day Offer — нужны ссылки

4. **Стиль:**
   - Канцеляризмы ("данные источники")
   - Слишком длинные предложения
   - Тяжеловесные конструкции

5. **Корректура:**
   - Возможны мелкие стилистические улучшения

## Альтернативный запуск

### Через основной скрипт:

```bash
cd multi_agent_review_system
python main.py ../test_text.txt
```

### Программно:

```python
from multi_agent_review_system import MultiAgentReviewSystem

# Прочитайте тестовый текст
with open('test_text.txt', 'r', encoding='utf-8') as f:
    text = f.read()

# Обработайте
system = MultiAgentReviewSystem()
result = system.process_text(text, save_results=True)

# Получите результат
final_text = result['document'].current_text
report = result['report']
```

## Troubleshooting

### Ошибка: "API ключ не найден"
```
export ANTHROPIC_API_KEY='your_key'
```

### Ошибка: "Rate limit exceeded"
Подождите несколько минут и попробуйте снова.

### Ошибка: "Invalid API key"
Проверьте корректность API ключа на console.anthropic.com

### Слишком долгая обработка
Это нормально — система делает много последовательных вызовов API. Подождите.
